# Karechahi documents

[Deploy to Cloudflare](https://deploy.workers.cloudflare.com/?url=https%3A%2F%2Fgithub.com%2Fapp2mulee%2Fkarechahi-documents)

Mobile-ready Persian estimates and proforma invoices. Site and bot backend run in one Worker. No build step is needed.

Open the deploy link, connect your GitHub and Cloudflare accounts, keep the default Worker name and deploy. If prompted, leave the build command empty and use `npx wrangler deploy` as the deploy command.

Register bot tokens only in the deployed application's settings. No real tokens are included in this repository. Initial management password: 8145; change it after installation. Saved tokens have no read endpoint. The deployment owner retains control of their Cloudflare infrastructure.
